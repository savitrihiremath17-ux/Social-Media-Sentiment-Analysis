# Social Media Sentiment Analysis Using Python

## About Project
This project analyzes social media reviews and classifies
them into Positive, Negative, and Neutral sentiments.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- NLTK
- Scikit-learn
- TF-IDF
- Logistic Regression

## Dataset
This project uses 5,000 synthetic social media reviews
created for educational and learning purposes.

## Project Workflow
1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis
4. Text Preprocessing
5. WordCloud Visualization
6. TF-IDF Feature Extraction
7. Logistic Regression Model
8. Model Evaluation
9. Sentiment Prediction

## Project Structure
- dataset: Original and cleaned datasets
- notebooks: Jupyter Notebook
- images: Charts and visualizations
- model: Saved ML model and TF-IDF vectorizer

## How to Run
Install the required libraries:

pip install -r requirements.txt

Open the Jupyter Notebook and run all cells.

## Disclaimer
This is an educational project using synthetic data.
Results may not represent real-world performance.
